# Archivo de scripts one-shot

Scripts de rondas pasadas de curación/promoción/fixes puntuales. Ya cumplieron su
propósito contra la BD viva y **no deben re-ejecutarse** (muchos asumen el estado
del catálogo de su ronda). Se conservan como referencia y como plantilla para
nuevos scripts targeted (estilo `link-ronda*-reviewed.ts`, ver CLAUDE.md).

Los imports fueron ajustados a `../../src/...` al moverlos; si copias uno como
plantilla de vuelta a `scripts/`, vuelve a dejarlos en `../src/...`.
